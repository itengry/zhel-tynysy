# Жел тынысы

Созерцательная браузерная игра о путешествии всадника через казахскую степь. Автопоход включён по умолчанию: можно ничего не нажимать и просто наблюдать.

## Запуск

Двойной клик по `ЗАПУСТИТЬ.command` или `index.html`. Интернет и установка зависимостей не нужны.

Для локального сервера:

```bash
cd "/Users/macbookair/Claude/Pet Projects/zhel-tynysy"
python3 -m http.server 8787
```

Затем открыть `http://localhost:8787`.

## Управление

- `←` — замедлиться.
- `→` — ускориться.
- `↑` — перейти на спокойную рысь.
- `↓` — остановиться.
- `Пробел` — включить или выключить автопоход.

На телефоне доступны четыре крупные touch-кнопки: замедлиться, остановиться, вернуть автопоход и ускориться. Панель становится почти прозрачной после нескольких секунд бездействия и возвращается по касанию экрана.

## Что уже работает

- автоматический спокойный шаг без участия игрока;
- восемь пикселизированных фаз всадника и лошади на сетке 96×128;
- три pixel-art биома 320×180: открытая степь, полупустыня и речная роща;
- жёсткая смена биомов без размытия и смешивания палитр;
- keyboard-управление на компьютере и touch-панель на телефоне;
- fullscreen safe-area интерфейс без внешних зависимостей;
- компактные PNG-ассеты общей массой менее 100 КБ.

## Материалы

- `ART_BIBLE.md` — камера, свет, палитра и правила совместимости ассетов.
- `GAME_DESIGN.md` — core loop, автопоход и план развития.
- `assets/characters/` — исходные cutout, character sheet, motion sheet и прозрачные кадры.
- `assets/biomes/` — исходные painterly landscape plates.
- `assets/pixel/` — рабочие pixel-art фоны 320×180 и кадры персонажа 96×128.

Текущая версия — vertical slice. Перед production-разработкой фоны нужно разделить на depth planes, а цикл лошади вручную выровнять по опорной точке и ground line.
